# Linux が何かを説明できる

## 1. OS とは

OS とは何かを、プログラミング初心者にわかるように説明してください。

OSとはオペレーティングシステムの略でコンプーターやスマホなどのデバイスを動かすための基本的なソフトのこと。ハードウェアとユーザーが使用するソフトウェア（アプリ）の橋渡しを行ったり、カーソルを動かしたりできる。コンピューター全体を制御する。
## 2. Linux とは

Linux とは何かを、プログラミング初心者にわかるように説明してください。

Linuxは代表的なOSの一つである。無料で利用できる。

## 3. カーネルとディストリビューションとは

Linux におけるカーネルとディストリビューションについて、それぞれプログラミング初心者にわかるように説明してください。

カーネルとは中核部分の制御を担当するプログラムのこと。アプリケーションが動作するための基本環境を提供している。

ディストリビューションとはLinuxの構成要素（カーネルやツールなど）をひとまとめにして、インストールすれば使える状態にした配布物を指す。簡単に言えばLinuxにおける流派のようなもの。

## 4. 有名なディストリビューション

ディストリビューションには色んな種類があります。有名なディストリビューションを3つ以上挙げてください。

Ubuntu(初心者向け）、Linux Mint(初心者向け)、Debian(システムのサーバーにもよく使われる）、

## 5. シェル

Linux はコマンドを使って操作をすることが多いです。その際に使用するソフトウェアがシェルです。シェルとは何か、プログラミング初心者にわかるように説明してください。またシェルには色んな種類があり、代表的なシェルを2つ以上挙げてください。

シェルとはユーザーがうちこんふぁコマンドをOSに伝えて実行する仲介役。シェルがあることでコマンドでコンピューターを操作できる。

bash	定番。多くの環境で使われている　

zsh	補完や見た目が強化されていて人気。macOSの標準シェル
